# 后台管理页减法重构

## 目标

本轮仅针对管理员首页结构和请求方式进行减法重构，不改变现有 Cloudflare Pages 项目、D1、R2、域名或部署方式。

## 首页变化

- 删除首页六项统计卡片，不再请求 `/api/admin/overview`。
- 删除三块赛道完成率大卡片，改为“全部赛道用户”标题下的总人数、已完成、未完成三个紧凑数字。
- 删除首页“任务材料审核”表格。
- “创建队伍”和“Excel 统一导入队伍”合并为“队伍管理”双标签模块。
- “添加用户”和“Excel 导入名单”合并为“用户管理”双标签模块。
- “活动广场管理”改为紧凑列表；详情、隐藏、排名和删除操作放入单条操作面板。
- 低频任务设置、最终截图、导出和管理员监督保留在“高级工具”入口，避免功能丢失。

## 请求变化

管理员首页初次打开只请求：

1. `/api/admin/completion-summary`
2. `/api/admin/users`

以下接口改为按需请求：

- 展开队伍管理后请求 `/api/admin/teams`
- 展开广场管理后请求 `/api/admin/plaza`
- 点击用户详情后再请求队伍和任务资料
- 点击高级工具后才运行原完整后台

用户搜索、筛选、翻页只更新用户区域；队伍和广场操作只刷新对应模块，不再整页重新加载。

## 可访问性与交互

折叠模块采用按钮、`aria-expanded`、`aria-controls` 和关联的 `region`。同一时间最多展开一个管理模块，减少移动端滚动长度和误操作。

## 构建方式

`scripts/apply-admin-dashboard-refactor.mjs` 会在本地启动、代码检查、测试以及 Cloudflare 部署前，对 `public/app.js` 做幂等转换：

- 原完整后台重命名为 `legacyAdmin`
- 插入精简后台实现
- 保留“高级工具”入口访问旧有低频功能

生成脚本重复执行不会重复插入代码。

## 验证

- `pnpm run check`
- `pnpm run check:text`
- `pnpm test`

生产部署仍使用现有 `jinshan20` Pages 项目和原 GitHub Actions 工作流。
