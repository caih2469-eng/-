# 微信图片二次提速部署说明

本版本基于 `PRODUCTION_MEDIA_LOGIN_PERFORMANCE.md` 的已完成修复，继续进行低风险图片参数优化。

## 改动

- thumb：最长边 360px，质量 0.72，目标上限 0.12MB。
- display：最长边 960px，质量 0.78，目标上限 0.7MB。
- 点击图片时复用已加载缩略图，展示图 decode 完成后再替换。
- 前后端尺寸校验同步。
- 静态资源版本提升到 `20260729-perf3`。

## 重要限制

- 仅新上传图片使用新参数。
- 历史图片不会自动重压缩或重写 R2。
- 部署后请上传一张新照片进行真机测试，不要只测试旧照片。
- 先部署测试环境，通过 iOS 微信、Android 微信、QQ 后再部署生产。
