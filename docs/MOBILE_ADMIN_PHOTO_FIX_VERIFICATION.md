# 手机管理端照片修复验收

本分支用于对当前 `main` 中的手机管理端照片修复做完整 CI 验证，不额外改变业务代码。

## 验收范围

- 点击用户卡片后立即打开打卡抽屉，不再等待全部队伍和全部任务接口。
- 用户卡片点击后不再因按钮 loading 恢复逻辑而破坏原卡片排版。
- 打卡抽屉只展示日期、任务状态和照片，不展示资料、队伍、补卡权限等多余区块。
- 管理端缩略图最长边为 540px，优先输出 WebP。
- 新互动赛道打卡同时写入展示图和 540px 缩略图。
- 历史私有照片通过安全回填生成 540px WebP 缩略图，原图和旧缩略图均保留。
- 管理员头部在手机端使用两列紧凑按钮，退出按钮独占一行。

## 自动检查

- `pnpm run check`
- `pnpm run check:text`
- `pnpm test`

## 实体设备验收

- Android 微信内置浏览器：进入管理端、点击用户、首张缩略图显示、连续打开同一用户。
- iOS 微信内置浏览器：同上，并检查返回、滑动关闭和图片查看器。
- 首次打开与 60 秒缓存内再次打开分别记录耗时。
