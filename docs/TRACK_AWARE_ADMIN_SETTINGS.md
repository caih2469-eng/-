# 分赛道用户与打卡设置

## 用户列表

管理员用户列表按赛道切换：

- 健康自律赛道（`health`）
- 四校区赛道（`interaction`）

每个赛道内继续保留全部、已完成、未完成筛选，完成统计和分页均只计算当前赛道。

## 健康自律赛道设置

- 开放/关闭健康自律赛道打卡
- 活动开始和结束日期
- 允许打卡的星期
- 每餐照片数量
- 早餐、午餐、晚餐各自的开始与结束时段

设置保存到现有 `app_config`：`healthCheckinSettings`，并同步兼容已有的 `startDate`、`endDate`、`slots` 和 `trackEnabled.health`。

## 四校区赛道设置

- 开放/关闭四校区赛道打卡
- 活动开始和结束日期
- 每日开始和结束时间
- 允许打卡的星期
- 个人打卡照片数量
- 队伍汇总照片数量

设置继续保存到现有 `app_config.checkinSettings`。

本改动不新增数据库表，不修改登录、补卡、队伍成员、队长、点赞评论或媒体桶规则。
