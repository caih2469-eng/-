# 廿载同心·青春同行打卡网站

这是当前已有的本地原型：包含活动宣传页、学生登录、双赛道身份资料、分时段截图打卡和管理员总览。它可以在单台 Windows 电脑上运行，但尚不具备公开互联网部署所需的完整安全性、并发存储和 Cloudflare 配置。

## 当前技术栈

- Node.js 原生 `http` 服务
- 原生 HTML、CSS、JavaScript 单页前端
- ExcelJS 负责服务端解析 `.xlsx` 名单
- 本地 JSON 文件数据库：`data/db.json`
- 本地图片目录：`uploads/`
- GitHub 默认分支：`main`
- 使用 Node.js 内置测试框架进行接口和权限测试
- 无 Cloudflare Workers/Pages、D1、R2、Wrangler 或 GitHub Actions 配置

## 本地启动

首次使用先安装依赖：

```powershell
pnpm install
```

Windows 用户随后可双击 `启动打卡网站.cmd`，或运行：

```powershell
node server.js
```

随后打开 `http://localhost:3000`。

当前代码内置原型管理员账号 `admin` 和默认密码 `change-me-now`。该凭据仅适合本地演示；当前版本没有修改密码功能，不应直接公开部署。

## 页面和功能

- 未登录：双赛道宣传页和现有登录入口
- 学生：只读查看姓名、学号、校区、所属赛道、账号状态和创建时间
- 自律健康赛道学生：查看当天三个时段、提交或更新截图
- 四校区互动赛道学生：查看队伍列表、邀请码加入和“我的队伍”
- 管理员：用户管理、Excel 导入、队伍名额、创建/修改/解散队伍、成员管理、提交审核和时段设置
- 管理员：双赛道任务、活动/赛道开关和任务材料审核
- 四校区学生：以队伍为单位保存草稿或最终提交图片和文案
- 自律学生：按早餐/午餐/晚餐个人提交并查看历史记录
- 活动广场：仅展示四校区队伍公开提交自动生成的帖子，支持最新、热门、月榜、分页、浏览和点赞
- 排行榜：日榜、周榜、月度队伍榜，综合热度按点赞归一化 70% 与浏览归一化 30% 计算

## 数据位置

- `data/db.json`：配置、用户和打卡记录
- `uploads/`：上传图片

图片会先在浏览器压缩；服务端只接受 JPG、PNG、WebP，压缩后单图最大 4MB。数据库只保存图片 URL，本地预览的对象文件保存在 `uploads/`；正式 Cloudflare 部署应切换为私有 R2。

活动广场不是论坛：没有自由发帖、评论或私信。管理员可隐藏、恢复或永久删除自动生成的广场帖子。

管理员可冻结月度最终排名并导出中文 Excel；冻结快照不会随之后的互动数据改变。

管理后台提供用户、队伍、今日提交、公开帖子、点赞和浏览数据看板，以及提交审核删除、帖子排名排除和六类 Excel 数据导出。

后期材料收集支持管理员创建个人/队伍任务，学生上传指定类型文件和总结，管理员鉴权下载、退回修改并导出未提交名单。材料文件保存在私有 `material-files/`，不会通过静态路径公开。

活动任务支持按“活动第 1、3、5 天”或指定星期自动刷新；每一期只能在当天管理员设置的时间段提交，最多 3 张且不可补交。四校区队伍由管理员 Excel 统一编组或手动调整，学生默认不能自行加入。

每个用户每天最多点赞 5 篇帖子；取消点赞会恢复当天额度。同一用户进入同一帖子详情，24 小时内只累计一次浏览，管理员浏览不计数。

这两个目录已被 `.gitignore` 排除。不要把真实学号、密码或活动材料提交到 GitHub。
